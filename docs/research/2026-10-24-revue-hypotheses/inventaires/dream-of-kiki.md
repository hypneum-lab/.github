## 1. Fiche projet

### 1.1 Idée centrale
Question de recherche (master spec `docs/specs/2026-04-17-dreamofkiki-master-design.md:29`) : *« Comment une IA peut-elle apprendre, mémoriser et organiser son savoir par le rêve ? »* — le rêve traité comme **fonction computationnelle** offline/asynchrone. Quatre piliers (L36-41) : A Walker/Stickgold → `replay`, B Tononi SHY → `downscale`, D Friston FEP → `restructure` (en série), C Hobson/Solms → `recombine` (branche parallèle REM). Le framework C (`docs/specs/2026-04-17-dreamofkiki-framework-C-design.md`) axiomatise ces 4 opérations en un semi-groupe non commutatif à budget borné (DR-0..DR-4), 8 primitives typées (α β γ δ ; canaux 1-4), une ontologie Dream-Episode (5-tuple), 3 profils emboîtés `P_min ⊆ P_equ ⊆ P_max`, un Critère de Conformité exécutable (DR-3) et un versionnage à deux axes **DualVer** `C-vX.Y.Z+{STABLE,PARTIAL,DIRTY,INVALIDATED}` (§12, L736-758). Deux papiers : Paper 1 (formel, cible PLOS Comp Bio depuis 2026-04-20, ex-Nature HB) ; Paper 2 (ablation empirique, venue TBD). Substrat de référence `kiki_oniric` (fork de `kiki-flow-core`), MLX/Apple Silicon.

## 2. Axiomes, invariants, définitions formelles

### 2.1 Primitives, canaux, profils, Dream Episode (spec framework C)
- **α — Raw traces** `Stream<ForwardPassTrace>` (P_max) ; **β — Curated episodic buffer** `AppendLog<EpisodicRecord>` (tous profils) ; **γ — Weights-only snapshot** `Pointer<CheckpointHandle>` ; **δ — Hierarchical latent snapshots** `RingBuffer<HierarchicalSnapshot>` (P_equ, P_max) (`framework-C-design.md:69-102`).
- **Canal 1** `WeightUpdate = (LoRAdelta, FisherBump)` (S1+S2) ; **Canal 2** `Queue<LatentSample>` (I3) ; **Canal 3** `TopologyDiff = List[TopoOp]`, `TopoOp ∈ {Add, Remove, Reroute}` (S3) ; **Canal 4** `Tensor[species, attention_weight]` (S4) (L106-128).
- **Profils** (L148-150, verbatim) : `P_min = { primitives_in: {β}, primitives_out: {1}, ops: {replay, downscale} }` ; `P_equ = { primitives_in: {β, δ}, primitives_out: {1,3,4}, ops: {replay, downscale, restructure, recombine_light} }` ; `P_max = { primitives_in: {α,β,δ}, primitives_out: {1,2,3,4}, ops: {replay, downscale, restructure, recombine_full} }`.
- **Dream Episode** (L214) : `DE = (trigger, input_slice, operation_set, output_delta, budget)` ; `trigger ∈ { scheduled(Δt), saturation(signal_type, threshold), external(event) }` ; `budget = max(FLOPs, wall_time, energy_J)`.
- **Ops** typées `Op : State × Budget → State × Output`, `State = (W, H, M)` (L251, L419) ; composition canonique `DE_canonical = replay → downscale → restructure (parallel: recombine)` (L312) ; `recombine` déclaré hors champ de DR-2 séquentiel (L317-327).

## 8. Avis critique

**Faiblesses méthodologiques visibles.** (1) *Puissance* : N=5/10 (MDE g≈1,4-1,85) pour les pilotes LLM et E-SNN, N=30 avec MDE réel d≈0,86 (erratum) pour la plupart des verdicts « RECOMBINE-empty », alors que l'effet attendu est g≈0,29 ; les « confirmations » H4-C→H6-C sont des non-rejets lus comme positifs (reconnu seulement en PR #41). (2) *Baselines fantômes* : Paper 1 §7 et la réplication cross-substrat cycle 2 reposent sur des mocks partagés (« true by construction ») ; Wake-Sleep CL est une constante publiée, pas un re-run ; le rêve n'a jamais été comparé à un contrôle SGD apparié avant le 06-19, où ce contrôle absorbe la moitié de l'effet. (3) *Fixtures* : trois fixtures dégénérées ou absentes (mega_v2 20 lignes, hellaswag 8 items, mmlu « sanity ») ont porté tous les « GO » LLM pendant deux mois ; la garde n'est arrivée qu'après la rétractation. (4) *Confusions* : P_equ ≡ P_max sur le chemin CNN (artefact non détecté de 05-03 à 10-24) ; EWC comme proxy de `restructure` ; restructure = permutation de blocs transformer (perturbation, pas apprentissage structurel) ; recombine latent « mog » sur une tête 2 classes ; rétentions E-SNN ≈ 0,51 (hasard) et CIFAR-10 ≈ 0,98 (saturation) rendent les contrastes inintéressants. (5) *Validité externe* : le seul substrat « réel » conformant est un numpy-LIF synthétique ; le seul verdict LLM réel est un nul sur Helium-2B/MMLU (où il n'y a presque rien à oublier) ; aucun 35B, aucun fMRI, aucun 3e point d'échelle. (6) *Incohérences inter-fichiers* : DualVer README 0.24 vs STATUS 0.25 vs pyproject 0.23 vs CITATION 0.10 ; tests 708/914/1077 ; gates G2/G3/G5/G6 « Pending » vs « LOCKED » ; README §scaling-law et H7 non amendés après la rétractation ; CHANGELOG « Closes #36 » vs issue ouverte ; byline « contributors » vs PI unique ; `golden_hashes` `pending_review` vs note « accepted » ; AXIOMS.md table « DR-2 Proven » vs corps « weakened ». (7) *Procédure* : préregs locales (git) et non filées sur OSF depuis le 04-21, délais lock→run de ~19 min, amendements §9.1 après probes d'epochs, cycle 1 « S5-S28 » exécuté en 86 commits sur 24 h, G3 revue externe jamais réalisée, arXiv jamais déposé.

**Ce qui survivrait hors paradigme LLM.** (a) L'ontologie **comptable** du rêve (DE borné, DR-0/DR-1, log `finally`, budget) est une discipline d'ingénierie transposable à tout système offline. (b) Le **Critère de Conformité C+** (typage + tests de propriétés + invariants bloquants) et sa falsification adverse (Q2/Q2+) sont un résultat de méthode indépendant du substrat. (c) La séparation **replay/downscale vs restructure/recombine** par domaine d'écriture (W vs H) reste une distinction utile ; la non-commutativité (op-pair) aussi. (d) La leçon empirique robuste est négative : à petite échelle, replay+downscale fait tout, les canaux « riches » n'ajoutent rien de mesurable — c'est une contrainte sur toute théorie du rêve computationnel. (e) R1/DualVer/préreg-sous-git sont des outils de rigueur réutilisables ; les hypothèses biologiques (K2, SHY, SO) ne tiennent, elles, que par des ancres méta-analytiques jamais mesurées sur un substrat réel.
