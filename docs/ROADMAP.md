# Roadmap

The quarterly roadmap is maintained in the lab's private repository
(`hypneum-lab/library`, `roadmap/ROADMAP.md`) since 2026-11-15. It is a
steering document (hour budget, hosts, dated decisions, incidents), not a
research record.

What stays public here:

- the hypothesis catalogue and its deltas, `docs/research/` (status of
  each claim, errata cited);
- the organisation profile, `profile/README.md`;
- the project-management rules, `docs/PROJECT-MANAGEMENT.md`.

Historical documents in this repository that cite `ROADMAP.md:<line>`
refer to the public versions of the file, which remain in the git history
of this repository (last public revision: 12449ff, 2026-11-11).
