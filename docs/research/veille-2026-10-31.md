## R3 — Transport optimal, JKO, attention (attributions « Inria/Peyré », « Stanford/UCLA Deep JKO/ICNN »)

Déjà vus (R3 du 24/10), rappelés pour le positionnement :
- **1502.06216** (2015-02-22) — Entropic Wasserstein Gradient Flows, Peyré (CNRS, Ceremade/Mokaplan). Schéma JKO entropique que kiki-flow implémente ; le plancher ε/(2τ) est un **biais** de ce schéma, pas une garantie. → Hypneum : fonde l'implémentation corrigée ; la revue R3 rappelle que le plancher est une borne asymptotique, pas un théorème à τ fini.
