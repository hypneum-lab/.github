## 1. Fiche projet

**Idée centrale.** « `kiki-flow-research` models the state of a large language model as four psycholinguistic activation densities (phono / lex / syntax / sem) that evolve under a Wasserstein-regularized gradient flow. The implementation solves the JKO scheme numerically on commodity Apple Silicon, extracts a compact neural surrogate for streaming inference, and integrates with existing MoE-LoRA routers through an advisory-only callback. » (`README.md:16-21`). Moteur amont du programme *dreamOfkiki* (pré-enregistrement OSF `10.17605/OSF.IO/Q6JYN`, `CITATION.cff:38-40`) ; package `kiki-flow-core` v0.0.1 (`pyproject.toml:3`). Trois pistes partagent `kiki_flow_core/` : T1 `track1_perf` (consolidation nocturne Eulerienne, 40 espèces hybrides = 4 × 10 stacks), T2 `track2_paper` (N particules Langevin × JKO, 4 espèces), T3 `track3_deploy` (surrogate NumPy pur, routage consultatif) (`CLAUDE.md:12-16`).

**Formalisme (sources code + papier).**
- Pas JKO : « ρ^{τ+1} = argmin_ρ { F[ρ] + (1/2h_τ) Σ_i W_2²(ρ_i, ρ_i^τ) } » (`paper/main.tex:171-175`) ; implémentation `JKOStep.step` = descente de gradient projetée sur le simplexe (`n_inner` sous-pas, clip 1e-12, renormalisation) puis, si `apply_w2_prox`, appel `prox_fn(rho, reference=rho_tau, epsilon=self.h, n_iter=100)` (`kiki_flow_core/master_equation.py:83-106`). Chemin « fast » = `apply_w2_prox=False` ; chemin « rigoureux » = `FullJKOSolver` (`epsilon=0.01` stocké mais **non utilisé** par le prox, qui reçoit `epsilon=h`, cf. `paper/rigorous_specialisation_2026_10_24/ANALYSIS.md:15-16` sur la branche #21).
- Énergie libre T2 : « F[ρ] = Σ_i ∫ρ_i V_i + Σ_i KL(ρ_i‖π_i) + ½ Σ_{i,j} J^sym_ij ∫ρ_iρ_j + λ_T 𝒯[ρ] » (`main.tex:178-183`), code `T2FreeEnergy.value` (`kiki_flow_core/track2_paper/paper_f.py:36-63`, Turing = Σ|∇ρ_i·∇ρ_k|).
- Décomposition J = J^sym + J^asym, ‖J^asym‖_F/‖J‖_F = 0.314 (Dell) / 0.330 (Levelt) (`main.tex:185-238`) ; matrices YAML `kiki_flow_core/species/data/{dell,levelt}_baddeley_coupling.yaml` (ordre `[phono, lex, syntax, sem]`, l.19/l.24).
- Prox W2 entropique (post-`ffee5d9`) : « argmin_q OT_reg(q, reference) + 2·epsilon·KL(q‖distribution) », Dykstra sur noyau de Gibbs `K = exp(-cost/reg)`, `reg = max(reg or epsilon, 1e-3)`, `lam = reg/(reg + 2τ)` (`kiki_flow_core/wasserstein_ops.py:58-99`) ; port MLX `mlx_prox_w2` (PR #16).
- Dérives non conservatives : b^asym_i = Σ_j J^asym_ij ρ_j (`main.tex:198-201`), b^phono = κ_B·clip(tanh(ρ_phono − ρ_lex), ±s) (`main.tex:276-281`) ; splitting opt-in `apply_drift_splitting` M = exp(h_d J^asym) (`paper_f.py:115-120`).
- Espèces (« 4 espèces du langage ») : phono / lex / syntax / sem ; T3 : 32 stacks par espèce, clés canoniques `"<species>:code"` (`kiki_flow_core/track3_deploy/eval/kl_species.py:11-18`).
- Métriques : entropie de Shannon en bits (max log2(grid) : 4 bits à grid 16, 6 bits à grid 64) ; gap = max − H ; KL en **nats** (`fast_vs_rigorous_kl.py`, `epsilon_sweep.py` : `np.log`) — libellée « bits » dans les versions ≤ v0.11 (`ERRATUM.md:128-130`) ; KL_total T3 = moyenne sur 4 espèces de KL(target‖pred) (`docs/superpowers/specs/2026-04-19-text-bridge-surrogate-design.md:177`) ; forgetting = max(0, immediate − final) (`main.tex:649-650`).

## 8. Avis critique

**Faiblesses (≤ 15 lignes).**
1. Reproductibilité : les résultats T3 pilot10k/scale50k (0.0785, 0.0736, R3 29.6 %, robustesse 3 seeds) ne sont étayés par **aucun artefact committé** (`/data/`, `/artifacts/` gitignorés, cache `/tmp`) ; le corpus 50k est annoncé avec 19 983 requêtes Qwen dans le papier mais construit `--no-synth` selon le tag — incohérence non résolue.
2. Erreur KL : un opérateur central est resté défectueux 6 semaines (POT) puis 6 mois (MLX) malgré 93→268 tests ; la CI hebdo reproduisait l'artefact. Le test de « dépendance à la référence » n'a été écrit qu'en octobre 2026.
3. Incohérence des versions : README (« v0.11 », « 84 min », « 93 tests »), `paper/CLAUDE.md`, bundle arXiv v0.5, `main.tex:901` et CITATION (« contributors », DOI v0.8 archivant les claims retirés) divergent de `main` ; la numérotation Gitea/GitHub des PR se chevauche.
4. Puissance statistique : sweeps à 1 seed (27/72 configs, pilot/scale), BoolQ 1 seed, λ̂ sur 3 paires, E1/E1b/E2 à seed 0 ; les « 3.4× σ » et « 0.3 % gap » ne sont pas des tests ; H2 rig seulement 5 seeds après coup.
5. Baselines : aucun comparateur de consolidation réel (replay, LoRA merge, EWC standard sur LLM) ; l'effet « bridge » (H17) est en réalité un prior Dirichlet aléatoire ; H18 (λ-monotonie) invoque un théorème dont les hypothèses sont réfutées par E2.
6. Modélisation : le « slow step » n'est pas réinjecté dans les particules (`multiscale_loop.py`), donc le « flot » T2 est une suite de pas JKO sur des histogrammes libres ; les potentiels asymétriques imposent la spécialisation que l'on « découvre » ; `FullJKOSolver.epsilon` n'est pas utilisé par le prox (ε = h).
7. Méta : réconciliation post hoc de la pente 0.60 présentée « No HARKing » ; mapping psycholinguistique reconnu comme hypothèse non testée (Q2 ouverte).

**Ce que le formalisme JKO apporterait hors LLM (5 lignes).** Le couple (énergie libre multi-espèces, prox W2 entropique, dérives non conservatives b^asym/b^phono intégrées par splitting à la Gallouët–Monsaingeon) est directement un schéma pour systèmes de réaction–cross-diffusion physiques (Turing, chimiotaxie multi-populations, écologie spatiale) où la positivité et la conservation de masse sont garanties par construction. Le protocole E1b (floor ε/(2τ), contrôle sans entropie, invariance de grille) est un banc réutilisable pour calibrer tout solveur JKO entropique. La décomposition J = J^sym + J^asym fournit un critère propre « gradient flow vs. dynamique à circulation » (auto-organisation hors équilibre). Le benchmark de spécialisation (gap d'entropie) mesure la brisure de symétrie spontanée de populations couplées sans référence au langage. Le résultat le plus solide du dépôt — la rigidité du prox W2 qui réduit la spécialisation d'un tiers — est un énoncé de physique numérique, pas de NLP.
